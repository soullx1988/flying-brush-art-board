- [x] 创建与编辑路径与飞书保持一致或接近。

- [x] 工具栏插入默认 `3×3` 表格。
- [x] 双击编辑单元格。
- [x] 方向键移动选中单元格。
- [x] `Tab` / `Shift+Tab` 前后移动。
- [x] `Enter` 提交并移动到下一行。
- [x] 支持 TSV/Excel 区域粘贴。
- [x] 拖动分隔线调整行高和列宽。
- [x] 在 tldraw 原生右键菜单中提供上方、下方插入行。
- [x] 在 tldraw 原生右键菜单中提供左侧、右侧插入列。
- [x] 在 tldraw 原生右键菜单中提供删除行、删除列。
- [x] 在 tldraw 原生右键菜单中提供清空单元格。
- [x] 支持整体移动、缩放、复制、删除、撤销和重做。
- [x] 表格规模上限暂定为 `50×50`。

### 第二阶段：飞书常用体验

- [x] 支持行选择、列选择和矩形单元格区域选择。
- [x] 支持批量复制、粘贴和清空。
- [x] 支持拖动行列重新排序。

## 四、技术架构 TODO

### 数据模型

- [x] 表格和思维导图分别作为一个业务对象，不拆成大量普通 tldraw shape。
- [x] 表格容器保存稳定的行 ID、列 ID 和单元格 ID。
- [x] 思维导图保存稳定的节点 ID、父子关系、顺序和左右侧信息。
- [x] 保证自动布局的确定性：同一数据在不同客户端生成相同位置。
- [x] 临时焦点、选区和正在输入的草稿不写入快照。

### 历史记录与操作

- [x] 文本提交形成独立撤销步骤。
- [x] 节点增删形成独立撤销步骤。

- [x] 所有右键操作复用 tldraw 原生菜单体系。
- [x] PNG、SVG 使用对应 `ShapeUtil` 的 SVG 输出；服务端 PDF 使用同语义 SVG 渲染器。
