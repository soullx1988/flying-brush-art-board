## 4. 破坏性矩阵与代码级故障注入

除 14 条 E2E 外，以下风险由隔离数据库、Mock 客户端、可配置小配额和程序化夹具覆盖：

- 内容、画板、引用和项目删除：根画板拒绝、被引用画板拒绝、删除引用不删除目标、项目级联清理且共享资产不误删。
- 版本冲突：旧 revision 保存返回 `REVISION_CONFLICT`，新数据不被覆盖。
- API/网络故障：剪贴板、引用、媒体上传、导入提交在中途失败时完整回滚；重复提交使用稳定 receipt，不重复创建。
- 自动保存与实时命令屏障：实时协作 store 未投影到服务端前，结构命令等待；超时则阻止命令，不采用旧快照。
- 导入会话：取消、过期、重复提交、容量淘汰及应用关闭清理通过。
- 恶意 `.iboard`：路径穿越、跨项目引用、重复 ID、损坏引用图在检查阶段拒绝，零持久化写入。
- 恶意媒体：活动 PDF、脚本/远程 SVG、伪装图片、超像素输入被拒绝或清洗。
- draw.io/tldr：XXE、XInclude、本地文件引用、非法记录及过量输入被拒绝，不发外部请求。
- Mock 飞书：未授权、取消、超时、限流、重复请求和凭证脱敏通过；inspect 阶段零写入。

## 7. 本轮发现并修复的缺陷

### P1-01 标签切换可能覆盖源画板实时 store

根因：`TldrawWorkspaceEditor` 在标签切换后仍持有旧 realtime Editor，目标画板快照可能被加载到源画板 store，并把删除同步回服务端。

修复：

- `dispose()` 清除旧 Editor 引用。
- 实时页面按 `boardId + inputSessionKey + attempt` 重建。
- 编辑器过渡窗口无 active editor 时安全保持只读。
- 新增回归测试；完整旅程连续 5/5 通过。

### P1-02 媒体/结构命令可能采用缺少最新分区的快照

根因：实时模式下桥接器 `getSnapshot()` 序列化的是脱离的 bridge store，而非当前挂载的 realtime editor store。媒体导入前的 flush 因而可能检查错误快照，导致新建分区被旧命令快照覆盖。

修复：

- `getSnapshot()` 优先序列化挂载的 realtime editor store。
- 结构命令前轮询服务端投影，只有与当前 document snapshot 一致时继续；超时返回 `REALTIME_SYNC_TIMEOUT` 并阻止命令。
- 新增“服务端追平后继续”和“永不追平时安全阻止”单元测试。
- 真实“分区 → 媒体 → 连线 → 导出/重导入”流程通过。

### P2-01 新建子画板标签短暂只读

已通过 Editor 生命周期清理、实时组件 key 和过渡期只读保护修复。最终标签 E2E 中活动标签无需先切走再切回即可编辑。

### P3-01 中文翻译和 tldraw CDN 资源警告

补齐：

- `action.copy-hovered-styles`
- `action.frame-selection`
- `page-menu.max-pages-reached`
- `page-menu.resize`

同时将 tldraw 5.2.5 字体、图标、嵌入图标及基线翻译本地化。最终用例未出现翻译缺失、`NetworkError` 或 CDN `Failed to fetch`。

### P2-02 原生右键菜单偶发不出现

确认根因是原生 tldraw/Radix 菜单关闭与下一次 `contextmenu` 到达之间的时序竞态，旧用例还因两个引用完全重叠且只断言菜单数量而存在假阳性。

- 保留 tldraw/Radix 原生菜单及其键盘导航、焦点和关闭行为；未新增自定义浮层。
- 菜单缺失时，在双动画帧和 80ms 稳定窗口内确认一次，并最多通过原生 Trigger 重放一次。
- 任意新的 pointerdown、Escape、左键操作和评论取消都会取消旧重放，右键拖动画布不会被兜底误判为菜单点击。
- 回归用例使用两个不同坐标的引用、真实鼠标右键，并验证菜单位置、选中 shape ID 和最终跳转目标；额外观察 160ms，排除“短暂出现后关闭”或旧坐标闪回。
- 完整 `board-reference-menu.spec.ts` 为 4/4 通过；核心连续右键用例重复 30 次为 30/30 通过；CanvasEditor 单测 18/18、根级类型检查和 Web 生产构建均通过。
