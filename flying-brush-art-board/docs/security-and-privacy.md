# 安全与隐私

## 本地数据与备份

本地启动器默认数据目录是仓库根目录的 `.infinite-board-data`：SQLite 数据库、内容寻址的 `assets` 目录及 `backups` 均位于此处；可通过 `INFINITE_BOARD_DATA_DIR` 或启动器的 `-DataDirectory` 显式覆盖。应用默认只提供本机回环服务，不会因为启动而公开画板到网络。

请定期运行 `scripts/backup.ps1`，并将备份放在工作仓库外的受保护位置。备份与恢复流程、恢复点和完整性校验见[备份与恢复](backup-and-restore.md)。不要直接编辑备份内的 SQLite、资源文件或 `.iboard` 压缩包。

## 飞书 OAuth 凭据

真实飞书导入仅在你显式配置并开启后运行。将 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` 和 `FEISHU_REAL_SMOKE=1` 放在本机 `.env.local`，不要发送到聊天、截图、日志、备份分享包或 Git。

默认测试和 CI 使用 mock，不读取 `.env.local`、不访问飞书网络。真实接口返回、token 和用户内容不得提交到仓库；如需测试样本，先匿名化并人工复核。

## 导入文件风险

只导入可信来源的文件。导入器会校验格式、大小、资源 hash、引用图和项目边界，但它不能替代来源可信度判断：文件仍可能含有令人误解的图文、外部链接或不适合的业务数据。

`.iboard` 合并会向当前 Project 新增 Board、资源和引用；它不会替换当前默认入口。先检查导入预览和统计，确认后才提交。对重要项目，请在导入前执行备份；导入失败或取消不应产生可见半成品。

跨 Project 粘贴的画板引用会降级为普通视觉卡片，避免把原项目的结构连接意外带入当前项目。

## 许可边界

本项目使用 tldraw 作为画布引擎。开发阶段仅在 localhost 使用，并应依照 tldraw 的适用许可取得授权；产品发布、托管、商业使用或超出许可范围的分发前，必须重新核对其当前许可条款。飞书 API 同样受飞书开发者平台的应用、权限和数据处理规则约束。

本文件不是法律意见。对含有个人信息、商业机密或受监管数据的画板，请按你的组织政策配置访问控制、保留周期、备份保管和删除流程。
