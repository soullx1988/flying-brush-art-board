# 用户指南

## 多画板与引用

一个 Project 可以有多个独立 Board。Project 首页和“全部画板”显示所有 Board；顶部只显示当前已打开的 Board 标签。

Board 之间的引用有两种类型：

- `embed`：用于嵌套关系。引用图必须是 DAG，不能形成环，任一访问路径最多 10 个 Board 节点。
- `link`：普通跳转。允许重复引用、自引用和循环，不会进入嵌套目录。

右键点击画板引用卡片可选择“进入画板”或“在新标签打开”。还可重命名目标 Board、切换引用类型或删除引用。删除引用只会解除两块画板间的关系，绝不会删除目标 Board。

“返回”按本次实际访问路径工作，而不是按固定父级工作。例如从 A 或 B 进入同一个 C，返回会分别回到 A 或 B。直接通过链接打开 C 时没有来源路径：界面会回到 Project 首页，并显示所有指向 C 的入站引用，供你选择来源。

如需删除一个 Board，先删除其全部入站引用；存在入站引用时系统会拒绝删除，避免其他画板留下失效跳转。

## 顶部标签页

标签是独立导航会话，不是 Board 的唯一实例。可在多个标签中打开同一 Board；每个标签单独保留访问历史、视口、选区和草稿状态。

- `Ctrl+Tab` / `Ctrl+Shift+Tab`：切换标签。
- `Ctrl+W`、中键：关闭标签。
- 拖动标签：调整顺序；标签过多时使用溢出菜单。
- 普通“进入画板”在当前标签跳转；“在新标签打开”创建新的会话。

同时打开同一 Board 时，存在未保存修改的会话会持有编辑租约；另一个实例暂时只读，防止两个会话互相覆盖。激活标签时会刷新当前 revision。

## 跨画板复制粘贴

在 Board A 复制普通元素，切换到 Board B 标签后可直接粘贴。新内容会生成新 ID；复制集合内部的分组、连线和绑定会一起重映射，未复制的外部绑定会断开。相同 SHA-256 的图片等资源会复用内容字节，不重复存储。

复制画板引用卡片时：

- 在同一个 Project 粘贴，会新建引用记录和卡片；`embed` 会重新检查环路和 10 层限制，失败时整次粘贴不会留下部分内容。
- 跨 Project 粘贴，不会创建跨项目引用，而会降级为普通视觉卡片，保留可读标题和来源信息。

包含引用或资源的粘贴、撤销和重做均按一次原子操作处理。

## 拖放导入与导出

拖到顶部标签栏或“＋”区域，会创建一个新 Board。拖到当前画布时：图片、SVG 和 PDF 作为当前 Board 的元素插入；`.tldr`、`.drawio` 和 `.iboard` 仍会走结构化导入流程。

- `.tldr`、`.drawio`：导入为一个可编辑 Board。
- PDF：导入为一个 Board，多页按顺序排列。
- `.iboard`：先显示检查结果，确认后将包内全部 Board、资源和引用图合并到当前 Project。系统会重映射 Project、Board、引用、Shape 和资源 ID，当前 Project 的默认入口不会被覆盖；导入包原来的入口会在新标签中打开，其余 Board 出现在“全部画板”中。

导入解析、校验、ID 重映射或提交失败时不会留下半成品。导出完整 Project 为 `.iboard` 可保留 Board、资源及 `references.json` 引用图；PDF 对共享 Board 仅输出一次。

导入前请阅读[安全与隐私](security-and-privacy.md)，需要可恢复副本时按[备份与恢复](backup-and-restore.md)操作。
